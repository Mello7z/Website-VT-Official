## 🎧 Sobre o projeto

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/ea2c333f-d6f8-4f9a-8c6b-a8cef459ffb0" />



O **VT Music** é um projeto de desenvolvimento web criado para representar a identidade digital do artista **VT**.

A proposta do site é fugir de um portfólio tradicional e transformar a navegação em uma experiência visual, combinando **música, estética urbana, animações e design cinematográfico**.

O site reúne os principais conteúdos do artista em um único espaço.

---

## ✨ Funcionalidades

* 🎵 Apresentação das músicas do VT
* 💿 Área de lançamentos
* 🎧 Player/preview de músicas
* 🖼️ Galeria visual
* 🎬 Conteúdo audiovisual
* 📱 Links para redes sociais
* 🌐 Design responsivo
* ✨ Animações e interações
* 🎨 Identidade visual própria
* ⚡ Navegação moderna e imersiva

---

## 🎨 Conceito visual

O projeto foi pensado com uma estética **dark, urbana e cinematográfica**, utilizando grandes elementos visuais, tipografia marcante e animações para criar uma experiência que combine com a identidade musical do VT.

A ideia é que o visitante não apenas encontre informações, mas **entre no universo do artista**.

---

## 🛠️ Tecnologias

O projeto utiliza tecnologias modernas de desenvolvimento web, como:

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* Animações e efeitos interativos
* Integração com plataformas de música e redes sociais

## 📱 Responsividade

O site foi desenvolvido pensando em diferentes tamanhos de tela:

* 💻 Desktop
* 📱 Smartphone
* 📲 Tablet

A interface se adapta para proporcionar uma boa experiência independentemente do dispositivo utilizado.
